# Egg Vampire

A first playable browser prototype for the Egg Vampire idle game.

## Run locally
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Current prototype
- Choose Knight, Ranger, Assassin, or Mage.
- Auto-battle through 3 Easy, 2 Medium, 1 Hard, and 1 Boss encounter.
- Collect eggs and gold from enemies.
- Forge equipment with 3 eggs, equipping upgrades automatically.
- Six equipment slots: Weapon, Helmet, Chest, Gloves, Boots, Accessory.

## Asset folders
Upload your art into `assets/characters`, `assets/gear`, `assets/enemies`, and `assets/castle`. Asset integration will be added after the images are uploaded.

This is an early gameplay prototype. Progress is not saved yet.
